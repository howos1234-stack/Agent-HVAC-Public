# Public repository agent rules

Read README.md, CURRENT_STATE.md, docs/development/WORK_PROTOCOL.md and relevant source/tests first.
This is a clean code snapshot, not a mirror of the private repository. Never import private history, PR dumps, manufacturer research, source PDFs, selection exports, credentials or personal records.
Use deterministic solvers, preserve SI units/provenance/mock flags and explicit failures. Do not change physical assumptions, frozen schemas or tolerances without a documented review decision.
Before edits inspect git status, report scope and create a record from docs/development_log/SESSION_TEMPLATE.md. Preserve others' edits.
Run locked base/gui tests, Ruff, mypy, manifest and build as appropriate; record exact SHA/commands/results and update CURRENT_STATE.md. NOT_RUN/BLOCKED are not PASS.
Branch from integration; open a PR. Never mirror or merge the private repository into this public one. Public visibility does not authorize third-party data publication or imply production/Gate approval.
