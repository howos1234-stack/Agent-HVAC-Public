# S2 고정 압력·유량 폐회로 수렴 검증

## 범위와 출처

S1의 기존 P02 압축기/등엔탈피 밸브 및 P05 병류 constant-UA HX를 그대로 사용한다.
[S1 물리/입력 근거](S1_HARNESS_VALIDATION.md), [두 트랙 계획](TWO_TRACK_PLAN.md).
냉매 물성은 CoolProp 8.0.0, 입력은 AGENT_ASSUMPTION/is_mock=true다.
R744, 30/90 bar(a), 0.1 kg/s, eta-is=0.8, HX 각각 UA=200 W/K 및 80 cells,
2차유체 각각 1 kg/s와 cp=1000 J/(kg K), 가스쿨러 290 K, 증발기 300 K.
DB/제품 데이터는 사용하지 않는다. 기존 부품/물성/공통 계약은 수정하지 않았다.

## 방정식과 수치 절차

미지수는 압축기 흡입 h 하나다. R(h)=h_return(h)-h이며 기존 회로를 순회해 평가한다.
설정 구간 430–500 kJ/kg을 14등분 scan하고 첫 유효 인접 부호변화 구간에서 이분법을 적용한다.
최대 100회이며 endpoint/중간 상태를 강제로 수정하지 않는다. 430 kJ/kg의 습증기 흡입은
유효하지 않은 상태로 기록한다. 무효 scan 점에서 이전 bracket 후보를 지우고,
중간점이 무효이면 즉시 해당 이유로 미수렴 처리한다. 전역 해 존재/유일성을 보장하지 않는다.

수렴 판정은 실제 노드와 부품 trace에서 독립적으로 계산한다:

- abs(h_return-h_trial) <= 0.01 J/kg.
- abs(p_return-p_trial) <= 1 Pa; abs(T_return-T_trial) <= 1e-4 K.
- abs(sum(Q_i+W_i))/max(abs(Q_i),abs(W_i),1 W) <= 1e-6.
- (max(m_i)-min(m_i))/max(m_i) <= 1e-12, 지정 유량과 HX trace도 포함.
- 같은 냉매, 올바른 부품 순서, 양의 냉동능력/압축동력/방열량 및 재압축 가능한 반환 상태.

Q/W는 냉매로 들어오는 방향이 양수다. COP=Q_evaporator/W_compressor이며 팬·펌프·모터는 제외한다.
질량 검사는 지정 유량 전달 일관성이며 압축기/밸브 유량 matching을 푼 결과가 아니다.
허용오차는 더 엄격하게만 변경 가능하다. h만 통과하면 종료하지 않고 온도/에너지 기준까지
계속 좁힌다. bracket 폭만 좁거나 반복한도가 끝난 것은 성공이 아니다.
미수렴 시 성능은 None이며 반복 이력과 마지막 부품 결과를 보존한다.

## 격자 검사와 발견 문제

초기 40/80-cell 비교는 COP 1% 기준에 FAIL했다: 40-cell COP=0.5263972189,
80-cell 대비 차이 1.24933949%. 폐회로 수렴과 공간 격자 정확도는 다른 조건이다.
40-cell을 지원 정확도 근거에서 제외하고 기본 80-cell을 유지했다. 1% 기준은 완화하지 않았다.
160-cell COP=0.5166817337, 80-cell 대비 0.6193757%로 PASS한다.
최종 회귀에는 기본 80-cell의 160-cell 비교를 남겼다. 40-cell 최초 실패는 삭제하지 않고
본 문서와 세션 기록에 보존한다. 모든 입력/운전점에 80 cells가 충분하다는 주장은 하지 않는다.

초기 집중 검사 1 failed / 47 passed는 위 40-cell 검사의 실패였다.
추가로 수렴 종료 조건 검토 중 h 기준만 통과하고 더 엄격한 에너지 기준이 남는 경우를 발견하여,
잔차가 0이 아닌 경우 계속 반복하도록 구현했고 1e-10 검사를 추가했다.
Ruff의 미사용 loop 변수 및 import/format 진단도 코드 정리로 해결했다.

## 실패 경계와 한계

테스트는 no-bracket, 전부 무효, 중간 무효 상태, 반복한도, float stagnation,
변조된 에너지/질량/온도/흡입 상태, 단위 변환, 입력 허용오차 및 overflow를 포함한다.
CLI 성공/실패 종료 코드와 S1 회귀도 검증한다. 전체 결과는
[세션 기록](../../../development_log/2026-09-22_WS-A_system-s2-convergence.md)을 참조한다.

이 결과는 고정 압력·유량 단일 운전점이다. 배관 Δp/열손실(S3), 운전조건 sweep(S4),
압축기 map/밸브 개도와 유량의 동시 해석, 습공기/서리/제어·과도해석은 구현하지 않았다.
P06 전체 완료, 제조사 검증, integration 병합 또는 Gate 승인을 뜻하지 않는다.
